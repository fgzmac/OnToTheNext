# D-123 — Recommendation-first Itinerary composer

Date: 2026-09-23
Status: Authorized for implementation by the CEO’s Pass 2 handoff; usability acceptance pending.

The Itinerary composer may embed shared Discover recommendations so an organizer can explicitly add an idea to the selected Day without changing sections. This narrowly supersedes the separate-page restriction in D-045/D-048/D-059/D-067/D-068/D-075. D-091’s explicit application capabilities, D-118’s operating model and D-122’s conditional dependency deferral remain in force.

RecommendationDecision and ItineraryItem remain separate. Standalone Accept means keep an idea; Add to Day explicitly accepts and schedules in one transaction. No duplicated ranking or decision engine, automatic scheduling of all Accepted ideas, or scattered booking workflow is authorized.

The CEO’s feedback supersedes the manual-first Pass 1 layout. Technical checks alone do not establish usability acceptance. Supported-city catalog provisioning, a selected-Day workspace and one shared detail panel implement this amendment; unsupported destinations retain manual planning. Today Slice 3 and the roadmap remain paused.
