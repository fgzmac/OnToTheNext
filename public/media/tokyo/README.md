# Tokyo pilot photograph credits

The per-image machine-readable manifest is `src/modules/discover/media-manifest.json`.
It records the original file page/title, photographer, applicable license and link,
matched experience, capture/observation date, alt text, dimensions and restrictions.
Each optimized photograph retains its stated original license, including ShareAlike
where applicable. These licenses apply to the photographs, not the application code.

All files are resized WebP derivatives with the full original framing retained.
The UI must not crop the Pokémon Center SHIBUYA photograph to isolate copyrighted
characters; its Commons file explicitly relies on de minimis treatment. Logos and
people in street photographs do not imply endorsement or a model release.

Planets is represented by an exterior photograph of its Toyosu venue; no Borderless
photograph or unlicensed interior artwork is substituted. Photos document a place
at the recorded capture date, not current merchandise, weather, crowds or access.
No event photo is supplied for the two future 2026 occurrences. Kyoto/Osaka photos
are outside this Tokyo pilot. Event/other-city gaps must remain explicit in the UI.
